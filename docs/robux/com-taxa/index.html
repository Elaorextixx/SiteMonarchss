Como funciona o Robux com taxa?

O Roblox retém 30% dos Robux enviados por Gamepass. Nesta modalidade, a Monarch calcula e envia Robux extras para cobrir esse desconto. Assim, depois que o Roblox retirar os 30%, você ainda recebe exatamente a quantia anunciada.

Exemplo: para você receber 1.000 Robux, enviamos aproximadamente 1.429 Robux pela Gamepass. Após os 30% do Roblox, restam 1.000 Robux.
